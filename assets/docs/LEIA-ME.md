# Documentos da Hi-Tech (PDF)

Para trocar um certificado, substitua o arquivo mantendo o mesmo nome. O botão aparece sozinho no site quando o arquivo existe.

| Arquivo | Onde aparece |
|---|---|
| `certificado-iso-9001.pdf` | Homologações, card ISO 9001:2015 |
| `certificado-iso-14001.pdf` | Reservado para a página ISO 14001 |

No WordPress, estes arquivos vão para a Biblioteca de Mídia, e o botão aponta para a URL do arquivo atual.
